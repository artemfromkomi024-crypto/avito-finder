# Моргай — напоминание моргать

Маленький красный полупрозрачный квадрат появляется в левой части экрана раз в 8 секунд.
Увидели — спокойно моргните. Работает на Windows (программа), а также на телефоне и Mac (веб-версия).

## Windows: BlinkReminder.exe

Готовая программа — один файл `BlinkReminder.exe` в этой папке. Ничего устанавливать не нужно,
подойдёт Windows 10/11 (встроенный .NET Framework 4.8).

1. Двойной щелчок по `BlinkReminder.exe`.
2. Программа работает в трее — значок может быть спрятан за стрелкой **^** рядом с часами.
3. Правый клик по значку: **Пауза**, **Показать сигнал**, **Настройки…**,
   **Запускать при входе**, **Выход**. Двойной клик — настройки.

Квадрат появляется **поверх всех остальных окон**, в том числе поверх полноэкранных программ.
Клики и наведение мыши он пропускает насквозь, так что работать не мешает.

По умолчанию: каждые 8 секунд, 56 px, непрозрачность 70 %, 5 % от левого края, по центру по высоте.

Настройки хранятся в `%APPDATA%\BlinkReminder\settings.ini` и меняются через окно настроек:
интервал, длительность сигнала, размер, непрозрачность, положение, звук.

Исходники и сборка — в папке `desktop/`:

```
desktop/BlinkReminder.cs   вся программа (WinForms + слоистое окно)
desktop/app.manifest       DPI-независимость
desktop/icon.ico           иконка
desktop/build.ps1          сборка через csc.exe из .NET Framework
desktop/tools/MakeIcon.cs  генератор иконки
```

Пересобрать: правый клик по `desktop/build.ps1` → «Выполнить с помощью PowerShell»
(или `powershell -ExecutionPolicy Bypass -File desktop\build.ps1`).

## Телефон и Mac: веб-версия

1. Откройте `index.html` в браузере (Safari на Mac, Chrome/Edge на Windows).
2. На телефоне нужен адрес страницы: загрузите папку на статический хостинг
   (Netlify Drop, Cloudflare Pages, GitHub Pages) и откройте ссылку. Затем
   «Добавить на экран “Домой”» — приложение откроется без адресной строки.
   Либо запустите в папке `python -m http.server 8000` и откройте с телефона
   `http://<IP-компьютера>:8000` в той же Wi-Fi сети.
3. На компьютере в Chrome/Edge можно нажать в настройках **«Открыть мини-окно»** — маленькое
   окно останется поверх других приложений.

Горячие клавиши веб-версии: **пробел** — пауза, **H** — скрыть панель, **Esc** — закрыть настройки.

## Файлы

```
BlinkReminder.exe     программа для Windows (главный вариант)
index.html            веб-версия для телефона и Mac
manifest.webmanifest  установка веб-версии на телефон/рабочий стол
sw.js                 офлайн-кеш веб-версии
icons/                иконки веб-версии
desktop/              исходники программы для Windows
```

## Ограничения

- Программа для Windows не требует браузера. Веб-версия требует открытой вкладки:
  если браузер свернуть надолго, он может «усыпить» таймер, и ритм начнётся заново при возврате.
- Для macOS отдельного .exe не бывает — там работает веб-версия (Safari).
- Если значок в трее не виден, проверьте скрытые значки Windows (стрелка **^**).
