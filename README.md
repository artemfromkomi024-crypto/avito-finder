# Авито-Финдер (Сыктывкар, мужская одежда)

Приложение для отбора **выгодных** объявлений: фильтры, сортировка по скидке к рынку,
оценка прибыли при перепродаже. Работает как PWA на телефоне, стоит 0 ₽/мес.

## Что уже готово

- `index.html` — сам интерфейс (мобильный, тёмная тема, фильтры, карточки)
- `data.json` — данные (сейчас демо-набор из 43 объявлений, чтобы показать заказчику)
- `manifest.webmanifest`, `sw.js`, `icon.svg` — чтобы «добавить на главный экран»
- `parser/avito_parser.py` — парсер Авито на Playwright (без прокси, 1–2 раза в день)
- `parser/config.json` — город, диапазон цен, список запросов, паузы

## Как считается «выгодность» (та самая неиронка)

Честно: это **статистика, а не нейросеть**. Работает так:

1. Для каждого объявления определяется бренд, категория, размер и «паль/оригинал»
   (по словарю брендов и ключевым словам в названии).
2. Считается **медиана цен** по группе:
   - сначала по `категория + бренд + паль/оригинал` (если в группе ≥ 3 объявлений);
   - если мало — по `категория + паль/оригинал`;
   - если совсем мало — по всему рынку (для пали берётся 60% от медианы).
3. **Скидка к рынку** = `1 − цена / медиана`. Метка «выгодно» — от 40%.
4. **Прибыль** = `медиана × 0.80 (торг) × 0.95 (продвижение) − цена`.
5. Сортировка: по скидке, по цене, по прибыли, по дате.

Почему медиана, а не «обученная модель»:
- нет данных о **проданных** ценах, только о запрашиваемых — любая «модель» на таких
  данных всё равно будет оценивать запрашиваемые цены;
- медиана устойчива к выбросам («продам за 100000, торг») и не требует обучения;
- когда накопится 500+ объявлений и появится история цен, можно подключить
  `scikit-learn` (градиентный бустинг по признакам: бренд, категория, размер,
  состояние, число фото, длина текста, рейтинг продавца). Это тоже бесплатно, локально.

## Запуск интерфейса

Просто открыть `index.html` в браузере — но из-за `fetch('data.json')` нужен локальный сервер:

```
cd avito-finder
python -m http.server 8099
```
и открыть http://127.0.0.1:8099

На телефоне: выложить папку на **GitHub Pages** (бесплатно) → открыть ссылку →
«Добавить на главный экран». Тогда это выглядит как обычное приложение.

## Запуск парсера

```
pip install -r parser/requirements.txt
python -m playwright install chromium
python parser/avito_parser.py
```

Что делает парсер:
- идёт по запросам из `config.json` (шорты, футболка, худи, свитшот, джинсы, куртка,
  кроссовки, кепка), город Сыктывкар, цена 1000–20000;
- паузы 15–40 секунд между страницами, видимый Chromium с постоянным профилем;
- если Авито вернул «Доступ ограничен» — прогон прекращается, старый `data.json` не портится;
- пишет `data.json` в корень проекта (его и читает приложение).

## Режимы парсинга

```
python avito_parser.py            # через SOCKS-прокси из config.json (нужен)
python avito_parser.py --no-proxy # напрямую (с домашнего IP Авито банит сразу)
```

Что проверено на практике:
- **прямое подключение** — `439`, блок (домашний IP в бане у Авито);
- **через армянский SOCKS** (`192.168.0.111:10808`, Ереван) — работает, но после
  **1–2 запросов** прокси тоже уходит в бан на время (обычно от 30 минут до нескольких часов);
- поэтому за один прогон реально собрать 1–2 категории, дальше `data.json` сохраняет
  уже собранное (слияние по ссылке) и дополняется в следующих прогонах.

Прокси из профиля твоего Firefox парсер не использует — он запускает свой экземпляр
Firefox с прокси из `config.json`. Отключать прокси в Firefox для парсинга не нужно.


Планировщик Windows:

1. `Win+R` → `taskschd.msc`
2. «Создать задачу» → триггеры: ежедневно 09:00 и 20:00
3. Действие: `python.exe` с аргументом `C:\...\avito-finder\parser\avito_parser.py`
4. Галочка «Выполнять только при подключении к сети», «Не запускать повторно».

ПК должен быть включён в эти моменты.

## Ограничения (обязательно сказать заказчику)

- **Не real-time**: обновление 1–2 раза в день, данные могут быть вчерашними.
- **Авито против парсинга** (правила сайта) и банит по IP. При частых запусках
  понадобятся прокси — это уже деньги. При 1–2 запусках в день шансы высокие, но не 100%.
- **Оценка рынка — по запрашиваемым ценам**, не по проданным. Медиана завышена,
  поэтому прибыль в карточке — оптимистичная верхняя граница.
- «Паль» определяется по словам в объявлении: продавец может не писать «реплика».
  Точнее — только по фото (это уже платная/сложная модель).
